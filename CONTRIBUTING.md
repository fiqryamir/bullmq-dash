# Contributing to bullmq-dash

Thanks for your interest. bullmq-dash is a modern BullMQ dashboard UI package — open-source, embeddable, and standalone.

## Current state

The project is pre-v1: the design and spec are being settled on the [wayfinder map](https://github.com/fiqryamir/bullmq-dash/issues/1). Until v1 ships, pull requests are **maintainers-only** — issues (bug reports, feature ideas, questions) are very welcome.

## Reporting issues

- Bugs → use the bug report template, include BullMQ and Redis versions plus a minimal reproduction.
- Feature requests → use the feature request template; check the open issues first — the roadmap is charted on the wayfinder map.

## After v1

PRs open up to everyone, review-gated. Full developer workflow docs (pnpm monorepo, packages layout) land with the v1 scaffold.
